# Event Management System

A React application for exploring events and managing event registrations.

## Requirements

- Node.js 20.19+ or 22.12+
- npm
- A Ticketmaster Discovery API key for the event features

## Run locally

1. Install dependencies: `npm install`
2. Start the development server: `npm run dev`
3. Open the local URL printed in the terminal.

Run `npm run build` to check the production build.

## API key

When the Ticketmaster feature is added, copy `.env.example` to `.env`
and replace its placeholder with your own API key. The `.env` file is
excluded from Git.

## Stack

React, Redux Toolkit, React Router, and Vite.
